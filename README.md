# InCubed — dati pubblici

Due file di dati sul programma ESA InCubed, rigenerati ogni giorno da
`activities.esa.int` e pubblicati qui perche' possano essere letti da un sito web.

| File | Contenuto |
|---|---|
| `kpi_incubed.json` | numero di attivita' totali, in corso e concluse |
| `activities_incubed.json` | elenco delle attivita' con titolo, stato, contraente, paese e link |

Sono le stesse informazioni gia' pubbliche sul portale ESA
<https://activities.esa.int>. Qui sono solo in un formato che un sito puo'
scaricare direttamente: quel portale richiede un browser completo per essere
consultato, quindi la raccolta avviene una volta al giorno in modo automatico e
il risultato viene depositato qui.

Aggiornamento: una volta al giorno. Nessun dato personale.
